# 连接、任务与制品传输契约（0.4.0）

调用链：Codex → 宿主聊天身份 → 策略与原生审批 → 持久任务/传输 → 系统 OpenSSH → 临时 Python helper。服务器不安装 Codex 或常驻代理。远端长任务会启动自己的监督进程，并保存私有状态以支持断线后查询。

## 连接与信任

主机详情的连接设置提供三种模式：

| 模式 | 配置与边界 |
| --- | --- |
| 兼容已有连接 | 保留旧地址/SSH 别名、严格 `~/.ssh/known_hosts` 校验和现有登录行为 |
| 受管连接 | 独立生成只读配置；每一跳单独指定账号、端口、私钥路径和固定公钥；最多 8 个跳板 |
| 原生 SSH 别名 | 用户明确勾选信任本机配置后交由系统 OpenSSH 处理 Include、Match、IdentityFile、ProxyJump 等；插件继续强制非交互和严格 known_hosts 校验 |

受管连接禁止 agent/X11/端口转发和 LocalCommand，不接受 ProxyCommand 文本。显式密钥只使用选定身份；未指定密钥时允许本机已解锁 SSH agent 与默认身份。插件不读取私钥正文。原生/兼容模式的本地配置可能包含可执行指令，属于用户信任的本机配置；外部编辑不会增加插件主机版本，变更后应重新核对授权。

公钥扫描只取得未信任候选，不自动接受。用户从可信渠道核对 SHA256 指纹后勾选确认；更换公钥需要匹配当前旧指纹。连接、跳板、密钥或指纹配置变化撤销旧聊天授权。内网主机无法直连扫描时可粘贴控制台取得的公钥。

连接超时 1–120 秒，保活间隔 1–300 秒、失败次数 1–10。POSIX OpenSSH 可使用 ControlMaster/ControlPersist，保留 1–600 秒；每跳独立 socket，路径过长拒绝。连接身份包含路由、公钥和连接参数，不跨配置复用。Windows 原生 OpenSSH 不提供该复用能力，界面和后端均禁用。已建立的连接不代表仍获授权，每个操作仍检查 Store。

固定能力探测和已有任务状态查询遭遇连接中断/超时时最多重连一次；提交、停止、文件写入和最终提交均不自动重放。连接诊断区分未知/变化公钥、认证失败、私钥不可用、解析失败、拒绝连接与超时。

## 长任务

后台任务默认关闭。可视化设置独立控制开启、Shell、环境变量名称、运行时间、输出及进程资源。自定义命令还需要用户启用原始 Shell 逐次审批；后台任务开关不会绕过普通命令策略。

| 工具 | 行为 |
| --- | --- |
| `ssh_job_submit` | 批准完整命令、cwd、Shell、env、时限、资源限制及断线继续行为后返回 `job.id` |
| `ssh_job_read` | 按字节 cursor 读取增量，返回 nextCursor/hasMore；默认同时核实远端 |
| `ssh_job_reconcile` | 查询已存在身份，绝不再次提交命令 |
| `ssh_job_cancel` | 新的原生确认后请求停止核实身份的进程组 |
| `ssh_job_list` | 分页列出本聊天记录，无 SSH |

相同聊天的相同 idempotencyKey 与相同完整快照返回同一任务；修改快照拒绝。开始联系 SSH 前持久化身份；远端以随机 token 和任务身份去重。进程控制验证 `/proc` 启动身份，不向复用的 PID 发信号。先到达的取消写入 token 绑定记录，阻止晚到提交执行。

执行状态与观察状态分开：退出码 0 且 confirmed/completed 才算成功。断线显示 observation=unknown；没有收到结果不等于远端未执行或失败。未知任务继续占并发额度，核实终态后释放，不能靠重启插件规避额度。控制操作不占执行额度，因此额度满时仍可查询或申请停止。

MCP 断开后已提交任务继续，由远端监督进程处理超时。撤销阻止后续远端访问，不等于回滚或远程 kill；重新授权后可核实或申请停止。取消仅针对核实过的进程组，已脱离该组的程序不保证被终止。RLIMIT 约束单个进程资源，不能声称是 cgroup 总量沙箱；root 的进程数限制不保证生效。

默认最长 3600 秒、最多 1 MiB 输出、CPU 3600 秒、单进程地址空间 2048 MiB、进程数 128。日志有 UTF-8 游标、截断标识、敏感模式及环境值检测；运行时不返回尚未结束的最后一行。并发查询保持输出前缀和游标单调；识别到敏感输出后不重新解密显示。stdout/stderr 在任务日志中合并以保留到达顺序。

远端要求 Linux、`/usr/bin/python3` 3.8+、进程组和 `/proc`。任务 helper 使用固定绝对路径、空环境和隔离 Python 模式。`/bin/sh`、`/bin/bash`、`/bin/zsh` 明确选择，未安装的 Shell 失败。能力探测不安装依赖，实际执行仍会检查运行条件。

## 制品传输

默认关闭；必须在可视化权限中同时指定本地和远端目录及读/写权限。上传要求本地读、远端写；下载要求远端读、本地写。目录可递归匹配或精确匹配；更具体的规则优先。递归遍历在计算摘要之前检查禁止路径和更具体的拒绝规则。

流程为 prepare → 审批 start → 后台流式传输 → 分页查询进度 → 校验 → 原子发布。prepare 冻结两端路径和根目录、禁止路径、源 inode/时间/大小/模式/SHA256、目标不存在条件及期限/大小上限。二进制正文经管道流转，不放进 MCP JSON、模型上下文或执行历史。

每次续传重新审批相同源内容和新的有效期；验证已传前缀 SHA256 后继续，结束时验证完整 SHA256。源改变、前缀变化、目标已存在、路径不安全时拒绝。恢复原传输沿用单一并发额度，新的控制审批独立记录且不可复用。每个传输使用 SQLite PID/token fencing，防止多个 MCP 进程同时接管或旧 worker 提交。

每次传输分块、远端请求、目录创建和最终发布检查有效授权；撤销/过期阻止后续流量与尚未发出的提交。提交已经发出后断线或撤销时可能返回 commit_unknown，恢复只能核实同一受管制品，不能声称未发布或已回滚。SSH 已发出的操作不能通过本地撤销原子撤回。

支持 `ssh_transfer_prepare/start/read/list/resume/cancel/cleanup`。cleanup 仅清理由该传输拥有且身份匹配的临时文件，不删除最终制品。递归传输通过 `ssh_transfer_manifest` 冻结有限文件清单，再用 `ssh_transfer_mkdir` 和逐文件 prepare/start 分别确认；不把“清单”当作整棵目录写入授权。

重要范围：

- 当前是受管 SSH 二进制流协议，不是 SFTP/SCP 兼容实现。目标使用新文件路径，仅支持 no-replace 原子发布；已有文本覆盖仍使用原文本工具。不能把任意现有制品覆盖包装成安全的原子 compare-and-swap。
- 本地制品通道目前支持 Windows、Linux；Linux 本机需 Python3 检查扩展属性。macOS 尚未实现等价的本地 ACL/xattr 检查，能力探测明确报告不可用并拒绝传输，不退回较弱检查；其 SSH 连接和远端任务能力独立。
- Linux helper 依赖 openat2；拒绝 symlink、hardlink、跨挂载、特殊文件、特殊权限和 ACL/xattr 源。普通模式/mtime 在平台允许时保留；文件由目标 SSH 账号拥有，不迁移 UID/GID。Windows 不导出 ACL，新文件继承目标目录 ACL。
- 新目录为 0700；目录清单由文件派生，不复制空目录、目录元数据或完整文件系统镜像。
- Windows 检查重解析点并拒绝链接，但不声称抵御恶意同用户进程并发替换文件系统。远端管理员、OS 及系统二进制必须可信。
- SHA256 证明传输内容一致，不证明二进制无秘密。二进制能力单独审批，保护目录仍不能访问；未知编码秘密不能靠文本模式检测保证发现。

默认单文件最多 1 GiB、清单最多 256 文件、最长 3600 秒，可配置最多 10 GiB/1000 文件/86400 秒。客户端缓冲与输出均有界，不把整份制品读入内存。

## 持久化、历史与兼容

Schema5 保留原有主机、权限、授权、审计和历史，只增加持久执行字段。旧策略补齐默认关闭的任务/传输配置。新增状态位于原数据目录的 `task-state/jobs.sqlite`、`transfers/transfers.sqlite` 和 `transport/`；数据不进入 Git。任务和传输记录跨插件进程重启可读。

普通执行历史仍保留 32 KiB 摘要和既有已结束记录清理规则；未知活动任务不会被历史清理释放。持久任务/传输记录当前不自动按历史保留期删除，以保留恢复身份；日志每任务有上限，但长期累计仍占本机磁盘。远端私有状态/提交 receipt 同样保留，不在插件重启时自动删除。

侧栏在原统一详情中新增连接/权限配置，在执行历史中选择普通记录、可恢复任务或制品传输。操作仍使用当前调用的即时原生确认，没有审批队列。

未提供 PTY 交互、密码安全存储、密钥轮换、SFTP/SCP 协议兼容或任意 SSH 客户端的完整沙箱。通用任务 API 未冒充 MCP Tasks 协议扩展；非 Codex 客户端还需提供可信聊天身份和所需原生确认能力。
